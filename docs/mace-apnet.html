01 / ARCH A

Pure MACE atomic model.

Drop AtomMPNN entirely. The frozen PolarMACE backbone supplies local representations and direct low-order density coefficients; small MACE-conditioned heads complete AP3D3's required atomic-property interface.

Direct from PolarMACE

q and dipole-like l=1 coefficients

Candidate low-order multipoles after explicit Condon–Shortley, axis-order, unit, origin, and charge-conservation checks.

Must be added

Quadrupole + response heads

Use equivariant l=2 hidden channels for a traceless Q readout; use scalar channels for HFVR/volume/polarizability proxies if AP3D3 induction retains them.

02 / ARCH B

Keep multipoles.
Replace representation learning.

The existing AtomMPNN/dimer-property model remains the source of q, μ, Q, HFVR, volume, electrostatics, and induction. Frozen MACE features replace or initialize AP3D3's learned-from-scratch atomic state.

Integration mode H1

MACE initializes AP3D3 h⁰

Project MACE invariants to n_embed, then retain AP3D3's trainable intramonomer message iterations and directional states. Closest to current implementation.

Integration mode H2

MACE replaces intra-MPNN

Feed projected MACE states directly into pair construction. Faster and cleaner, but removes the current directional intramonomer path; recover angular information with invariant contractions or an equivariant pair head.

03 / ARCH C

MACE-featurized
multipole atom model.

Use one frozen MACE representation twice: first as the input to a trainable equivariant/invariant atom head that predicts the complete AP3 atomic-property contract, and again as the chemical state for AP3D3 intermolecular component residuals.

Atom-model objective

Supervise structure, not just energy

Use atomic multipole targets when available plus molecular charge/dipole constraints, covariance tests, traceless Q projection, response-property losses, and optional long-range energy consistency.

Shared-feature objective

One frozen pass, two trainable consumers

Cache MACE node irreps once per monomer. The atom-property head and AP3D3 pair adapter consume the same cache with separately versioned schemas.

04 / FEATURE TAP

Irreps-aware extraction.

The adapter is not a generic flatten operation. It separates scalar invariants for the current AP3D3 MLP from covariant channels used by multipole heads.

05 / PAIR CORE

Inside the AP3D3 pair block.

MACE enriches the atom state; AP3D3 still owns explicit intermolecular construction, bidirectional symmetry, component readouts, and dimer aggregation.

06 / ENERGY ASSEMBLY

Physics anchors.
Neural corrections.

All proposed architectures must preserve the same additive long-range structure: MTP-MTP electrostatics, classical_induction, and D3. The AP3D3 network learns component residuals around those asymptotically correct anchors.

07 / BUILD ORDER

De-risk in five visual checkpoints.

P0

Feature tap + long-range parity harness

Load pinned polar-1-s; identify node irreps; verify batching and symmetries. Freeze a common evaluator for MTP-MTP (damped/undamped), classical_induction, and D3 so every architecture is compared with the same asymptotic spine.

Figure unlocked
Fig. 04 tensors and Fig. 06 classical terms have measured, versioned schemas.
P1

Hybrid architecture B

Keep existing AtomMPNN properties and DimerProp long-range branch. Replace AP3D3 atomic embedding with projected MACE features using H1, then ablate H2.

Decision gate
MACE representation beats the AP3D3 baseline on identity/scaffold splits.
P2

MACE-featurized atom model C

Train equivariant q/μ/Q heads and invariant HFVR/volume/α/damping heads from frozen MACE irreps. Enforce charge sum and tensor covariance; compare MTP-MTP and induction energies against the existing AtomMPNN provider.

Decision gate
Multipole, electrostatic, and induction parity pass before AtomMPNN removal.
P3

Direct PolarMACE route A

Validate direct density coefficients as q/μ candidates, complete Q and response properties, and compare against C. This isolates whether explicit atom-head supervision is necessary.

Ablation gate
Direct outputs must match C's physical constraints and long-range energy accuracy.
P4

Final architecture selection

Benchmark A, B, and C with the same MTP-MTP / classical_induction / D3 configuration, pair-head capacity, splits, seeds, and component targets.

Final selection
Choose on accuracy, asymptotics, calibration, latency, memory, and interface simplicity.
